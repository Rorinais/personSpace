## JS 核心概念

JavaScript 是 Web 开发的核心语言。ES6+ 新特性：箭头函数、解构赋值、模板字符串、Promise、async/await、模块化。

## 与 Vue 的关系

Vue 基于 JavaScript，深入理解 JS 是学好 Vue 的前提。重点：响应式原理、闭包、this 指向。

> 掌握 JS 基础后可以开始学习 Vue。[查看 Vue.js 笔记 →](/note/vue)
