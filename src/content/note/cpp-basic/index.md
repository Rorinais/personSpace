## C++ 概述

C++ 是一种高性能编译型语言，广泛用于游戏开发、图形引擎、操作系统。

## 核心特性

- 面向对象（类、继承、多态）
- 内存管理（new/delete、智能指针）
- 模板编程
- STL 标准库（vector、map、algorithm）
- 现代 C++（C++11/14/17/20）
