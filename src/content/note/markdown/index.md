Markdown 是一种轻量级标记语言，用纯文本就能写出格式丰富的文档。本页面搜集了最常用的语法，每个示例都是"源码 + 效果"对照，一目了然。

## 标题

用 `#` 开头即可创建标题。数量代表级别，从 `#` 到 `######` 共六级。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 强调

让文字 **加粗**、*倾斜* 或 ~~划掉~~，几种语法可以叠加使用。

```markdown
**粗体**  *斜体*  ~~删除线~~
```

**粗体**  *斜体*  ~~删除线~~

## 引用

在段落前加 `>` 就变成了引用块，适合引用别人的话或做重点提示。

```markdown
> 引用文字
```

> 引用文字

## 列表

无序列表用 `-` `*` `+`，有序列表用数字加点，缩进可以嵌套子列表。

```markdown
- 项目 A
- 项目 B
  1. 子步骤 1
  2. 子步骤 2
```

- 项目 A
- 项目 B
  1. 子步骤 1
  2. 子步骤 2

## 链接

`[文字]` 放链接文本，紧接着 `(地址)` 放目标 URL。

```markdown
[GitHub](https://github.com)
```

[GitHub](https://github.com)

## 图片

和链接语法类似，前面加一个 `!` 即可。括号里是图片地址，方括号里是替代文字（图片加载失败时显示）。

```markdown
![替代文字](图片地址)
```
