## Vue 3 基础

Vue 3 是一个渐进式 JavaScript 框架，采用 Composition API 提供更灵活的代码组织方式。

## 核心概念

- `ref` / `reactive` — 响应式数据
- `computed` — 计算属性
- `watch` — 侦听器
- 组件化开发
- 路由管理（vue-router）

本项目（个人空间网站）就是使用 Vue 3 + Vite + Element Plus 构建的。涵盖了路由管理、组件通信、响应式布局等实际应用。
